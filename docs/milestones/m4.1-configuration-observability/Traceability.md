# M4.1 요구사항 추적표 (설계 재개 사이클 3)

상태: **설계 재개 사이클 3 — 구현 전**.
[Design_Review_Resume_Cycle_2.md](Design_Review_Resume_Cycle_2.md)가 기록한
MAJOR `R2-MAJ-01`과 MINOR `R2-MIN-01`을 닫기 위해 재개했다. Iteration 1~5,
설계 재개 사이클 1의 폐쇄 판정과 설계 재개 사이클 2의 독립 재검증(§2)은
감사 이력으로 보존하며 재작성하지 않는다 — 이번 사이클은 §2 표 끝에
`R2-MAJ-01`/`R2-MIN-01` 행을 추가하고, R1-MAJ-01 행을
[Design_Review_Resume_Cycle_2.md](Design_Review_Resume_Cycle_2.md) §6의
재판정("미폐쇄 — R2-MAJ-01로 계승")에 맞춰 정정하며, REQ-006.2/REQ-006.4
행의 "테스트"/"증거" 컬럼을 Design §10.4 항목 6의 수정된 recording wrapper
계약(존재하지 않는 공개 `.wraps` 속성 대신 `assert_called_once_with`/
`call_args.args[0]`/`real_fn(tmp_path)` 위임 결과 비교)에 맞춰 갱신한다.
`설계 symbol`은 [Design.md](Design.md) 재개 사이클 3 기준. `증거`는 승계된
Iteration 1 executable check(Design §2), Iteration 2 개정 계약(Design
§3~§10), [Design_Review_Iteration_3.md](Design_Review_Iteration_3.md)의
M3-01/M3-02/m3-01/m3-02/t3-01 폐쇄, [Design_Review_Iteration_4.md](Design_Review_Iteration_4.md)의
M4-01/m4-01/m4-02/t4-01 폐쇄, [Design_Review_Iteration_5.md](Design_Review_Iteration_5.md)의
`M5-01`/`m5-01` 폐쇄,
[Design_Review_Resume_Cycle_1.md](Design_Review_Resume_Cycle_1.md)가 발견하고
[Design_Review_Resume_Cycle_2.md](Design_Review_Resume_Cycle_2.md)의 독립
재검증(§6)이 확정한 `R1-MAJ-02` 폐쇄, 또는 이번 재개 사이클이 제공하는
`R2-MAJ-01`/`R2-MIN-01` 폐쇄 증거(§2 하단, 다음 독립 리뷰가 확인할 대상)이다.
`R1-MAJ-01`은 사이클 1에서 발견됐으나 사이클 2 독립 검증에서 미폐쇄로
재판정됐고, 그 후신인 `R2-MAJ-01`이 이번 사이클에서 비로소 실행 가능한
계약으로 폐쇄된다(§2 R1-MAJ-01/R2-MAJ-01 행 참고). 41개 필드 전수는
[Field_Spec_Inventory.md](Field_Spec_Inventory.md). Phase 라벨은
[Plan.md](Plan.md) Phase 0~3과 Design §11.1 정합.
